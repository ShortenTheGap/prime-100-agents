# prime-100-agents — Prime 100 Team Pack

Over-the-air delivery channel for the **Prime 100** app's `my-ai-team` folder.
Files here are synced into a member's my-ai-team folder by the Prime 100 companion
(`prime-ascent/companion`, `server/teampack.mjs` -> `server/packs.mjs`).

Layout mirrors the target folder:
- root `.claude/**` + `CLAUDE.md` = the **general** (Sue) pack -> `manifest.json`
- `packs/dev-team/**` = the **dev-team** (Manny) pack -> `manifest-dev-team.json`

`manifest.json` / `manifest-dev-team.json` are generated by
`prime-ascent/companion/scripts/build-manifest.mjs` (general: no subpath;
dev-team: `PACK_URL_SUBPATH=packs/dev-team`). The source of truth is the app's
bundled `companion/team-packs/`.

This repo is Prime 100 ONLY. It is separate from Prime Agent Desk's `primeagents`
channel by design — never mix content between the two apps.
