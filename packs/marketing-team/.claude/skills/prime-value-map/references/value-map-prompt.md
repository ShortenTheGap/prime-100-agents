# Prime Value Map Prompt — Framework

Using the ideal buyer persona provided by the user, generate a comprehensive client value map. This map outlines the journey from the client's current state to their desired state, including key milestones along the way.

## Output Structure

### Current State (Point A)

Provide a detailed description of the ideal client's present situation, including:
- Their main problems and challenges (business and/or personal)
- Their emotional state (frustration, overwhelm, fear, confusion, etc.)
- The specific circumstances keeping them stuck
- What their day-to-day experience looks like with this problem

Go deep. This isn't a surface-level summary — it should feel like you're reading the client's mind about where they are right now.

### Desired State (Point B)

Paint a vivid picture of the ideal client's ultimate goal state, including:
- Their transformed business/life situation
- Their emotional state after achieving the outcome
- Specific outcomes and results they've achieved
- How their relationships, status, and daily experience have changed

This should be aspirational but believable — the kind of outcome that makes the reader think "that's exactly what I want."

### Key Milestones (5 Total)

Identify 5 crucial milestones the client must reach to progress from Point A to Point B. These should represent the real steps of the transformation — not generic advice, but the actual shifts that need to happen.

For each milestone:

**a) Title:** A clear, concise name for this milestone

**b) Why it matters:** Explain its importance in the client's journey. Why can't they skip this? What happens if they get stuck here?

**c) 3 Sub-topics or challenges:** List 3 specific challenges, questions, or obstacles the client faces within this milestone. These should be the real things they struggle with — not textbook answers.

**d) 3 Content ideas:** Suggest 3 types of valuable content that could be created to address this milestone. Think about what would genuinely help someone at this stage: educational posts, case studies, frameworks, myth-busting, how-to guides, etc.

### Transformation Summary

Write a paragraph summarizing how progressing through these milestones transforms the client's situation. Emphasize the emotional and practical journey from Point A to Point B. This should feel like a narrative arc — not a bullet list.

### Content Strategy Overview

Provide a brief overview of how the entire value map can be leveraged into a content strategy that:
- Demonstrates expertise at every stage of the journey
- Builds trust by addressing real problems (not just surface-level advice)
- Positions the user as the guide who understands the full transformation
- Creates natural pathways from content consumption to engagement to conversion

## Guidelines

- All elements must be tailored to the specific needs, challenges, and goals of the buyer persona provided
- The output should be detailed, actionable, and reflect deep understanding of the client's journey
- Use the language and tone the target audience uses themselves
- Focus on specificity — generic milestones like "set goals" or "take action" are too vague
