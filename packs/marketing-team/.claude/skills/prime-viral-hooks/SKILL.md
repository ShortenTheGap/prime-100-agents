# Prime Viral Video Hooks Generator

Generate 50+ viral YouTube video hooks tailored to your specific audience and offer. Uses proven viral content frameworks from top-performing creators to craft curiosity-driven, click-worthy hooks that stop the scroll.

## Critical Rules

1. **Never invent specific statistics, revenue claims, or results in hooks.** Do not write hooks like "How I Made $2.3M Using AI" or "The Strategy That Generated $500K in 90 Days" unless the user provided those exact numbers. Use placeholder brackets instead: "How I Made [$ amount] Using [method]" or write hooks that don't require specific proof claims (e.g., "The AI Strategy Nobody Is Talking About").

2. **Hooks are templates the user fills with their real numbers, not fictional case studies.** If a hook pattern requires a specific result or dollar amount, either use the user's provided data OR use bracket placeholders like [result], [timeframe], [$ amount]. The user must be able to publish these without fabricating claims.

3. **No fabricated client names, testimonials, or case study references.** Hooks like "How Sarah Went From $8K to $34K Months" are only acceptable if the user provided Sarah's story. Otherwise, use generic framing: "How One Client Went From [before] to [after]."

4. **Output is a clean numbered list. No meta-commentary.** No "How to use these hooks," "Why these patterns work," or "Tips for maximizing CTR" sections. Just the hooks, then the short-form optimization offer.

## How to Generate the Hooks

Once inputs are collected, read `references/viral-hook-frameworks.md` for the proven hook structures and example patterns, then generate 50+ original hooks.

### Hook Requirements

Every hook must be:

- **One sentence long** -- Punchy and impossible to ignore
- **Curiosity-driven** -- Creates an information gap the viewer needs to fill
- **Specific** -- Uses numbers, timeframes, or concrete details FROM THE USER'S INPUT (or bracket placeholders)
- **Tailored** -- Directly relevant to the user's target audience and offer
- **Publishable as-is** -- The user should be able to use any hook without needing to verify fabricated claims

### Hook Categories to Cover

Generate hooks across these proven viral structures (aim for variety -- don't lean too heavily on any one category):

1. **The "X% Don't Know" hook** -- "99% of [audience] don't know this [topic] strategy"
2. **The "If I Had to Start Over" hook** -- "If I had to rebuild my [business type] from scratch, here's exactly what I'd do"
3. **The "Ultimate/Best" hook** -- "The best [topic] strategy on the internet"
4. **The "$X in Y Days" hook** -- ONLY use real numbers from user input, or use brackets: "How I [result] in [timeframe]"
5. **The "Mistakes" hook** -- "Avoid these X [topic] mistakes that are killing your [metric]"
6. **The "Secret/Hidden" hook** -- "This [topic] trick will [surprising benefit]"
7. **The "How to Without" hook** -- "How to [desired result] even if [common objection]"
8. **The "Tools/Hacks" hook** -- "These [topic] tools feel illegal (but they work like magic)"
9. **The "Brutally Honest" hook** -- "X years of [topic] advice in Y minutes"
10. **The "Warning/Urgency" hook** -- "You're losing $$$ if you don't know these [topic] hacks"
11. **The "Full Blueprint" hook** -- "If I wanted to [ambitious goal], this is what I'd do [FULL BLUEPRINT]"
12. **The "Get Ahead" hook** -- "How to get ahead of 99% of [audience type]"
13. **The "Controversial Take" hook** -- Challenges a common belief in the market
14. **The "Watch This If" hook** -- "Watch this if you're tired of [common frustration]"
15. **The "I Did X to Prove Y" hook** -- Personal proof/demonstration hook (use real examples only)

### Formatting

- Number all hooks sequentially (1-50+)
- Each hook should stand alone as a complete YouTube title
- Incorporate power words: "secret," "ultimate," "insane," "exactly," "blueprint," "proven," "shocking," "nobody talks about"

### Quality Standards

- No generic or boring hooks -- every single one must create curiosity
- Use FOMO elements where appropriate (urgency, exclusivity, hidden knowledge)
- Incorporate the user's specific niche language, metrics, and audience pain points
- Mix up hook lengths -- some short and punchy, some longer with specifics
- Avoid repetitive patterns -- if 5 hooks in a row start with "How to," vary the structure
