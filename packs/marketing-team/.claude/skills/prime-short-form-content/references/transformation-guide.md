# Script Transformation Guide — Complete Reference

This file contains the complete methodology for transforming scripts into high-performing short-form videos. All framework names and source references are internal only — never surface them to the user.

---

## Script Structure

Every transformed script follows this 4-part structure:

### 1. Hook (First 3–5 seconds)
Open a psychological loop that makes the viewer need to keep watching. The hook must:
- Immediately clarify what the video is about
- Challenge a common belief or approach
- Create curiosity that can only be satisfied by watching

A hook is psychological first, visual second. The visuals amplify the psychology.

### 2. Explanation (Next 10–15 seconds)
Explain why this matters and why the typical approach doesn't work. This is where you establish the stakes.

### 3. Illustration (Next 15–20 seconds)
Make the concept concrete and relatable using one of:
- A story with specific details
- An analogy that connects to something familiar
- A specific example with real numbers
- A case study with before/after

### 4. Lesson/Payoff (Final 20–30 seconds)
Deliver the actionable value that closes the loop opened in the hook. This is the "aha moment" — the thing they came to learn.

## Hook Types

Select the most appropriate type based on script content.

### Authority + Insider Knowledge
**Use when:** The creator has strong credentials to leverage
**Pattern:** Position as having exclusive knowledge others won't share
**Openers:** "Let me tell you something that nobody in [industry] is going to teach you about [topic]..."

### Problem-Agitation
**Use when:** The audience is likely making a common mistake
**Pattern:** Call out the mistake directly and create tension
**Openers:** "If you're [common action], you're probably doing it wrong because [reason]..."

### Contrarian Belief
**Use when:** There's a widely-held belief you can challenge
**Pattern:** Identify the "biggest mistake" and flip conventional wisdom
**Openers:** "The single biggest mistake [audience] make is [common belief]..."

### System/Process Promise
**Use when:** Teaching a system or process
**Pattern:** Promise a framework or set of principles that solves the problem
**Openers:** "If you want [desired outcome], you have to follow [these X principles]..."

### Curiosity Through Naming
**Use when:** You can brand a concept with a memorable name
**Pattern:** Give a familiar concept an unfamiliar, intriguing name
**Openers:** Introduce the named concept and let curiosity do the work

## Creating Memorable Concept Names

When the script contains a teachable concept, consider giving it a branded name.

**The principle:** Take familiar, everyday words and combine them in a way that feels novel. The viewer recognizes each word individually but the combination is unfamiliar — creating a curiosity loop.

**How to create them:**
1. Identify the core concept being taught
2. Find 2–3 familiar words that capture the essence
3. Combine them in an unexpected way
4. The name should be: memorable, descriptive, and proprietary-sounding

**Examples of the pattern:**
- A method for audience targeting → combine familiar words into something like "Audience Fit Score"
- A principle about content pacing → name it something like "The Momentum Curve"
- A framework for selling → brand it as "The Trust Ladder"

Apply this technique when it naturally fits. Not every script needs a named concept.

## Strong Opening Phrases

- "Let me tell you something that most people in [industry] won't share..."
- "Here's what nobody tells you about..."
- "The single biggest mistake is..."
- "What most people don't realize is..."
- "Here's what separates [successful people] from everyone else..."

---

## Language and Tone

### Do:
- Use direct, commanding language ("You have to," "You need to," "Here's what works")
- Be conversational but strategic
- Use specific numbers and metrics for credibility
- Include credibility anchors (specific results, client names, track record)
- Create urgency when genuine

### Don't:
- Use filler words or hedging language ("maybe," "kind of," "sort of")
- Make claims without backing them up
- Be controversial for controversy's sake
- Use corporate jargon

## Call-to-Action Options

End every script with one of these:

**Resource Offer (Preferred):**
"If you want [specific resource], comment '[KEYWORD]' and I'll send it over."

**Follow/Engagement:**
"If this helped, save this and follow for more."

**Self-Referential Close (when the script demonstrates its own principle):**
"And here's what's interesting — I just used [the technique] throughout this entire video. Watch it again and you'll catch it."

## Visual Techniques Library

Select techniques based on script content. Describe in practical terms to editors.

### Blurred Steps Reveal
**When:** Script presents 3+ steps or principles
**Editor note:** "Show all steps on screen but blurred/redacted. Reveal each one as the speaker discusses it. Creates anticipation and progress."

### Hidden Word Reveal
**When:** Introducing a key term or concept name
**Editor note:** "Display the key word with only first and last letters visible (middle blurred). Reveal at the specific moment. Builds curiosity."

### Letter-by-Letter Framework
**When:** Introducing an acronym or multi-part system
**Editor note:** "Animate each letter/component appearing on screen as it's explained. Keep previous letters visible so the full framework builds visually."

### Wrong vs. Right Contrast
**When:** Contrasting a mistake with the correct approach
**Editor note:** "Show the wrong approach with a red X or 'WRONG' overlay. Transition to correct approach with green checkmark."

### Animated Stats/Numbers
**When:** Citing specific statistics or results
**Editor note:** "Animate numbers appearing on screen. Use counting-up effect or graph visualization for dynamic, credible feel."

### Key Phrase Text Overlays
**When:** Critical phrases, especially in the hook
**Editor note:** "Add bold text overlays with spoken words. Use color or size to emphasize most important terms."

## Emotional Hook Matrix

Match visual and emotional treatments to script content.

### Short-Term Wins (Excitement)
- Feeling: Quick excitement, "I can do this"
- Visuals: Immediate results, checkmarks, progress indicators
- Pacing: Fast cuts, upbeat, bright

### Big Picture Goals (Inspiration)
- Feeling: Desire, possibility, freedom
- Visuals: Lifestyle imagery, freedom/travel, success moments
- Pacing: Slower, cinematic, warm tones

### Pain Points (Urgency)
- Feeling: Discomfort with inaction, "I need to fix this"
- Visuals: Clocks ticking, wasted time, stressed scenarios
- Pacing: Tense, darker colors, glitchy

### Mental Barriers (Breakthrough)
- Feeling: "I've been stuck, but I can break through"
- Visuals: Walls breaking, lightbulb moments, transformation
- Pacing: Start constrained, release into bright/open

## Quality Checklist

Before delivering, verify:
- Hook opens a clear psychological loop in the first 3–5 seconds
- Script follows Hook → Explain → Illustrate → Teach structure
- Memorable concept name created when appropriate
- Credibility anchor included (specific numbers, results, or experience)
- Topic resonates with existing fans, casual viewers, AND new audiences
- CTA is clear and actionable
- Word count is 200–350 words (60–90 seconds)
- Editor instructions are practical and specific
- Emotional approach is identified with matching visual treatment
- No internal framework names appear in user-facing output
