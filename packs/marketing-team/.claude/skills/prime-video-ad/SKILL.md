# Prime Video Ad Writer

Write 60-120 second teaser video ad scripts that capture targeted attention on social media and drive clicks to a sales page, eCom product page, or VSL. These ads don't sell -- they create an intense emotional itch that only clicking through can scratch.

## Critical Rules

1. **The script IS the deliverable.** Do not add a "Block Deployment Analysis," "Why This Structure Works," "Copy Block Breakdown," or any analysis section after the script. The script is complete on its own.

2. **Include visual direction inline, not as a separate section.** Visual cues go in brackets within the script itself, not in a separate "Visual Notes" appendix.

3. **Only use statistics and claims from the user's copy blocks.** Never invent proof points, client numbers, revenue claims, or conversion metrics that weren't in the provided input.

## Core Philosophy

These ads exist to capture targeted attention and facilitate the sale -- not make it. We take prospects who are casually scrolling through social media and move them from an oblivious state (completely unaware of our product) into a receptive state where they're excited to learn more.

We create an emotional "itch" using copy blocks, then place the CTA at peak itchiness. Anything that scratches the itch -- that explains, educates, or satisfies curiosity -- kills the ad.

We never refer to the destination as a "sales message," "sales page," or "offer." People love to buy but hate being sold to. We're getting prospects excited about discovering something that will improve their lives in a specific, tangible way.

## What the User Provides

### Copy Blocks (Required)

The user provides their own copy blocks -- never use the examples from the reference material. For a full explanation of each block with examples, read `references/copy-blocks-guide.md`.

The five blocks at a glance:

1. **Pain/Problem:** The specific pain or problem prospects are currently experiencing. Best expressed as "problem tokens" -- symptoms described the way prospects experience them in daily life, not boring clinical terms.
2. **Promise:** Specific, desirable outcomes that move the prospect from who they are now to who they want to be. Should live on the edge of believability -- almost too good to be true, but plausible enough that prospects want to believe.
3. **Curiosity:** The unique mechanism, hidden cause, or novel solution that bridges pain to promise. Teased, never explained. Includes visual curiosity for the video medium.
4. **Proof:** Credible proof (experts, studies, institutions) and social proof (testimonials, case studies, UGC snippets). In video ads, the most effective proof comes directly from users speaking.
5. **Constraints:** Identity, values, belief, experience, and resource limitations that prospects feel will prevent them from getting results. Great ads dismiss these by showing others who had the same constraints yet succeeded.

### Market/Product Details (Helpful)

Any additional context about the target audience, product, or sales page helps tailor the ad.

## Writing Rules

1. **60-120 seconds.** Every ad must fit this window.
2. **Use only the user's copy blocks.** Never the examples from the reference material.
3. **90-95% copy velocity.** Nearly every line must establish or intensify one or more copy blocks. No fluff, no filler. This is interruption marketing -- each line must earn its place.
4. **Never scratch the itch.** Don't explain the mechanism. Don't educate. Tease and intensify.
5. **Never call it a sales message.** Frame the CTA as discovering, learning, seeing, or watching something.
6. **Include visual direction.** These are video ads. Every section should include scene descriptions, visual transitions, and visual curiosity elements in brackets. Show AND tell simultaneously across multiple modalities.
7. **Use visual curiosity as pattern interrupts.** Especially in opening frames. Visual curiosity doesn't need to follow tight logic -- it needs to divert expectations and stop the scroll.
8. **Stack copy blocks, don't isolate them.** The best lines hit multiple blocks at once.
9. **CTA must be benefit-rich.** Attach the call to action to a specific emotional reward. Incorporate Promise or Proof into the CTA itself.
10. **Experiment with structure.** Use dramatic demonstrations, UGC simulation, multiple points of view, aggressive scene cuts, split screens. Variety in structure keeps ads fresh.

## How to Write the Ad

1. Read the user's copy blocks carefully. Identify the strongest, most compelling elements.
2. Read `references/copy-blocks-guide.md` for deep understanding of each block and how to deploy them in video format.
3. Read `references/sample-ads.md` to study how the five blocks combine in finished scripts with visual direction.
4. Choose the most compelling copy block for the opening hook.
5. Draft the script with visual direction inline throughout.
6. Review: Is copy velocity at 90-95%? Does any line scratch the itch? Cut it. Does it fit 60-120 seconds?

Deliver the script. That's it. No analysis after.

## Edge Cases

- If the user doesn't provide copy blocks, ask for them before writing. Explain the five blocks if needed.
- If the user wants multiple variations, write each with a different structural approach (different opening hook, different POV, different visual style).
