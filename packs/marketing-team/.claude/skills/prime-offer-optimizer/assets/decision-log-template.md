# Decision log template

Use this structure for `Avatar/Offer Decision Log.md` in the main team. Short dated entries, newest first. Read it before you propose anything.

```
# Offer Decision Log: [offer name]

## [date]
- ACCEPTED: [the change, in one line] (Offer v[X.Y])
- REJECTED: [the change] | Reason given: [the owner's reason, in their words]
- DEFERRED: [the change] | Revisit when: [the condition the owner named]

## [earlier date]
- ...
```

## Rules

- A rejected change does not come back unless new evidence arrives. When it does, propose it again in the same sentence as the new evidence, and never without it.
- Record the owner's own reason, not your summary of it. The reason is what tells the next session whether anything has changed.
- A deferral carries the condition that would reopen it. "Later" is not a condition.
- Log the decision, not the discussion. One line each.
- This file is the member's record. It lives with their offer files, never inside this skill.
